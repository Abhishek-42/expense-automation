# Project Changelog

This document tracks all significant modifications and technical decisions made to the Expense Automation system.

---

## [2026-02-25] - Deduplication & Deterministic Hashing
**Files Modified:** `backend/app/main.py`

### Changes Made:
- **Replaced Random UUIDs:** Removed `uuid.uuid4()` generation for transactions and subscriptions in DynamoDB records.
- **Implemented Deterministic Hashing:** Imported `hashlib` to generate predictable MD5 string hashes.
  - **Transaction IDs:** Now generated by hashing `user_id + date + description + amount`.
  - **Subscription IDs:** Now generated by hashing `user_id + merchant_name`.
- **System Impact:** This solves a critical bug where uploading the same CSV multiple times resulted in duplicated database rows and corrupted data. DynamoDB will now deterministically UPSERT (overwrite) identical records.

---

## [2026-02-25] - Dedicated Subscriptions Dashboard
**Files Created:** `frontend/dashboard.html`, `frontend/dashboard.css`, `frontend/dashboard.js`
**Files Modified:** `frontend/app.js`, `frontend/index.html`, `frontend/style.css` 

### Changes Made:
- **Architectural Split:** Isolated the "Subscriptions Table" out of the main `index.html` login/upload page into a standalone dedicated frontend web page.
- **Protected Routing:** JavaScript logic in `dashboard.js` prevents access to the dashboard unless a valid JWT token is found in the browser's `localStorage`.
- **Automatic Redirection:** Modified the CSV upload logic in `app.js` to automatically redirect the user to `dashboard.html` exactly 1.5 seconds after a successful file processing event.
- **Mathematical Aggregation:** `dashboard.js` iterates over the `GET /subscriptions` API response not just to render data, but to proactively calculate the strict Estimated Monthly Total based on the billing cycles of all active subscriptions.
